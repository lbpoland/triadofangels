Search tips

Use shorter queries and the right follow-up route

Good search is not only about the input field. It is also about knowing when to broaden the query, switch scopes, or stop searching and open the better browse surface instead.

Keep it short

Start with the clearest part of the title

Shorter phrases often produce better matches than long sentence-like queries, especially on music and publishing routes.

Switch scopes later

Search broadly first, narrow second

The quickest first pass is often All, then a scope filter only when the result set is too broad or the wrong pillar dominates.

Stop searching when browse is better

Use Music, Publishing, Lyrics, or Videos for discovery
